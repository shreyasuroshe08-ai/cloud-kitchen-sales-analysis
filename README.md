# Cloud Kitchen Sales & Profitability Analysis

## Project Overview

This project analyzes cloud kitchen sales, orders, revenue, and profitability using Microsoft Power BI. It helps identify business trends, compare kitchen performance, and understand financial variations.

## Tools & Technologies

* Microsoft Power BI
* Power Query for data cleaning and transformation
* DAX for calculations and KPIs
* Data visualization and business analysis

## Project Objectives

* Analyze total sales and total orders.
* Track sales trends over time.
* Compare revenue by city and zone.
* Evaluate kitchen profitability and P&L variance.
* Identify performance differences across kitchens.

## Dashboard Features

### Dashboard 1: Sales Analysis

* Total Sales
* Total Orders
* Sales Trend
* Orders by Value
* Revenue by City
* Revenue by Zone

### Dashboard 2: Variance-Level P&L Analysis

* Variance-based categories
* Average variance percentage by NET_REVENUE segment
* Monthly store-count analysis
* NET_REVENUE, EBITDA, and contribution analysis

Data cleaning, data modeling, DAX, KPI development, interactive dashboards, and business insights.
